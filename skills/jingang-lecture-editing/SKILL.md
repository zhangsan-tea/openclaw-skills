# 金刚经讲读稿·语义重排编辑规范

## 项目概况

- **原始素材**：企微文档《金刚经_王德峰_讲读整理稿_上一版备份》，约120k字符，21章
- **原始章节目录**：`/tmp/jingang_chapters_raw/`（按章切分的原始长段落版）
- **输出目录**：`/Users/sanzhang/obsidian-private/outputs/金刚经_王德峰_完整字幕/上一版备份_语义重排_version_a/chapters/`
- **最终交付格式**：MD + HTML + DOCX 三种

## 编辑原则（三不改）

1. **不改原意**：忠实还原讲座口语内容，不做文学润色
2. **不删强调**：口语中的刻意重复/强调句保留（如"就是海水。这些都融会贯通了"）
3. **不删注音**：保留拼音注释，如「南无(námó)」「般若(bōrě)」「乐(yào)」

## 三步流程

### Step 1：OCR 清理 + 标点修正

- 修正 OCR 重复字（如"乐乐"→"乐"）
- 删除 OCR 噪声字符（如散落的"学"、乱码序列"M士N日"等）
- 合并被错误断开的句子
- 规范标点：中文句号/逗号/问号/叹号，书名号完整配对
- **统一中文引号**：引语一律用弯引号 `“”`，不得出现直引号 `"`（Write 写入可能把弯引号退化为直引号，落盘后须用脚本按「开→闭交替」规则统一转回弯引号，并校验左右配平）
- 修正明显错字（不确定的保留原文加括号标注）
- 经典引文、历史人物语句与口语残句若无音频佐证，不凭通行版本擅自改写；只处理确定的OCR噪声和语法残缺

### Step 2：语义段落重排

**核心规则：按完整语义单元分段，不按标点机械切分。**

#### 段落长度目标
- **目标区间**：100–500 字/段
- **上限弹性**：核心论理段（如"如如之心"论述）可放宽至 ~550 字
- **下限**：50 字以下的孤立段必须合并（除非是独立引文）

#### 六条硬规则（从第一章踩坑中提炼）

| # | 规则 | 典型反例 | 正确做法 |
|---|------|----------|----------|
| 1 | **逗号不断段** | `这个心体，`¶`佛家讲的心体…` | 逗号后的内容归入下段 |
| 2 | **无孤悬片段** | `…程度。我们`¶`今天一起讨论…` | "我们"归入下段，保持句子完整 |
| 3 | **语义连续不切断** | `最尊最上最第一。`¶`一种最高的度…` | 论点→论据→结论 保持同段 |
| 4 | **同一话题讨论归一段** | "乐"字三种读音被中间切断 | 整个话题讨论归一段，在话题转换处分段 |
| 5 | **三句义完整** | 三句义论述（如来说X，即非X，是名X）被拆散 | 一组三句义及其解释保持同段 |
| 6 | **引文+解释同段** | 引用经文后立刻断段 | 经文引用与紧跟的解释放在同一段 |
| 7 | **先辨句法再合并** | `不是你去降伏，`+`那些发了菩提心的人…`直接拼成“降伏那些人” | 先判断后句主语、前句宾语和口语停顿，避免合并后改变原意 |

#### 分段锚点选择（优先级递降）

1. **话题转换**：从讨论 A 概念转向 B 概念
2. **叙事转折**：时间/人物/场景切换
3. **论证层次**：从举例转向总结、从总结转向新论点
4. **长段内的自然呼吸点**：一个完整论证链结束，下一个开始

### Step 3：通读复查

逐段检查：
- [ ] 有无孤悬片段（几个字单独成段）
- [ ] 有无逗号结尾的段落
- [ ] 有无超 550 字的段落需要拆分
- [ ] 有无语义被硬切的段落需要合并
- [ ] OCR 残留是否清干净

## 章节命名规则

- 序号从 00 开始，对应原始章节顺序

## 常见陷阱

- **错误粘连改变句法**：原稿的逗号或换行可能代表口语停顿，不能只删除分隔符机械拼接；须先判断主谓宾关系。
- **用通行版本覆盖讲者原话**：典故、经文或名言疑似有误时，若没有音频依据，不直接替换成记忆中的标准表述。
- **段落过碎但形式合规**：即使每段都超过100字，也要复查“例证—解释—结论”是否被拆散；段长合格不等于语义完整。

## 注意事项

- 每章处理完后推送给用户看，确认后再继续
- 段落调整用 Edit 工具逐处修改，不要整文件重写（保留 git diff 可追踪性）
- 用户可能反馈个别段落不合理，按反馈微调即可
