# 金刚经讲读稿·语义重排编辑规范

## 项目概况

- **原始素材**：企微文档《金刚经_王德峰_讲读整理稿_上一版备份》，约120k字符，21章
- **原始章节目录**：`/tmp/jingang_chapters_raw/`（按章切分的原始长段落版）
- **输出目录**：`/Users/sanzhang/obsidian-private/outputs/金刚经_王德峰_完整字幕/上一版备份_语义重排_version_a/chapters/`
- **最终交付格式**：MD + HTML + DOCX 三种

## 硬性约束（用户 2026-09-01 下达，最高优先级）

用户原话，逐条照录，任何情况下不得违反：

> **【硬性约束】**
> 1. **绝对禁止腰斩句子**：所有换行/分段点，必须严格落在整句的末尾标点（。！？以及紧随其后的”’）之后。绝不可在逗号（，）、顿号（、）或句子中间断开。
> 2. **杜绝碎头碎脑的短句分行**（避免微信对话式分段），单段字数建议保持在 **150～400 字**之间（包含 **3～6 个完整句子**），保持段落的丰满与逻辑完整度。
> 3. **遇到人物对话、重要转折、时间/空间跨越或核心观点升华时，才设立新自然段。**

### 约束落地细则

| 约束 | 机检方式 | 违反即返工 |
|---|---|---|
| 段尾合法 | 正则 `[。！？][”’）\)]?$`，每段必须匹配 | 逗号/顿号/冒号/破折号/分号结尾 → 合并到下段或上段 |
| 段长 150–400 | `len(段)`；<150 必须并入相邻段，>400 必须拆 | 拆不动时说明，不得硬塞 |
| 段不碎 | 每段 ≥3 个完整句（防 1–2 句孤段） | 单句成段 → 合并 |
| 分段触发 | 只有「对话 / 转折 / 时空跨越 / 观点升华」四种 | 仅为"读起来长"而分段 → 重排 |

### 字数与句数冲突时的裁决（重要）

讲稿是口语体，**平均句长仅 15–20 字**。机械套用"3–6 句"会让每段只剩 60–120 字，反而违反 150 字下限。因此：

- **以字数为主要尺度**（150–400 字），句数只作**下限保护**（≥3 句，防碎段）
- 口语段 150–400 字通常对应 **5–15 句**，属正常，不算违规
- 真正要卡的是上限：单段 >400 字或 >15 句时才优先拆，拆点仍须落在整句末尾

### 可复用质检脚本（每章落盘后必跑）

```python
python3 -c '
from pathlib import Path; import re
s=Path("<章节路径>").read_text(encoding="utf-8")
ps=s.split("\n\n")[1:]          # [0] 是标题行
sent=lambda t:[x for x in re.split(r"(?<=[。！？])",t) if x.strip()]
issues=[]
for i,x in enumerate(ps,1):
    t=x.rstrip()
    if not re.search(r"[。！？][”’）\)]?$",t): issues.append(f"[{i}] 段尾非法 ...{t[-20:]}")
    if len(t)<150: issues.append(f"[{i}] 过短 {len(t)}字")
    if len(t)>400: issues.append(f"[{i}] 过长 {len(t)}字")
    if len(sent(t))<3: issues.append(f"[{i}] 句数不足")
print("段数",len(ps),"| 字符",sum(map(len,ps)),"| issues:",issues or "无")
print("弯引号",s.count("\u201c"),"/",s.count("\u201d"),"直引号",s.count(chr(34)),
      "书名号",s.count("《"),"/",s.count("》"))
print("ASCII",sorted(set(re.findall(r"[A-Za-z][A-Za-z0-9]*",s))))
'
```

ASCII 只允许出现讲者原话里的英文词（如 `devotion`、`New Concept English`）和拼音注音字母（`bōrě` 之类），其余一律是 OCR 残留，须清除。

## 编辑原则（三不改）

1. **不改原意**：忠实还原讲座口语内容，不做文学润色
2. **不删强调**：口语中的刻意重复/强调句保留（如"就是海水。这些都融会贯通了"）
3. **不删注音**：保留拼音注释，如「南无(námó)」「般若(bōrě)」「乐(yào)」

## 三步流程

### Step 1：OCR 清理 + 标点修正

- 修正 OCR 重复字（如"乐乐"→"乐"）
- 删除 OCR 噪声字符（如散落的"学"、乱码序列"M士N日"等）
- 合并被错误断开的句子
- 规范标点：中文句号/逗号/问号/叹号，书名号完整配对
- **统一中文引号**：引语一律用弯引号 `“”`，不得出现直引号 `"`。落盘后用脚本校验 `直引号数量==0` 且左右弯引号配平；若检出直引号，再按「开→闭交替」规则批量转回弯引号
- 修正明显错字（不确定的保留原文加括号标注）
- 经典引文、历史人物语句与口语残句若无音频佐证，不凭通行版本擅自改写；只处理确定的OCR噪声和语法残缺

### Step 2：语义段落重排

**核心规则：按完整语义单元分段，不按标点机械切分。**

#### 段落长度目标（用户 2026-09-01 最新硬性要求，优先于旧区间）
- **目标区间**：**150–400 字/段**，每段包含 **3–6 个完整句子**
- **严禁腰斩**：分段点必须落在整句末尾标点（。！？及紧随其后的”’）之后；逗号、顿号、句中一律不断
- **杜绝碎短段**：避免微信对话式分段，保持段落丰满与逻辑完整；<150 字的段必须并入相邻段
- **弹性**：核心论理段（如"如如之心"论述）上限可放宽至 ~550 字；密度极高的短章个别段可略低于150字，但须确认并入后不会超400字

#### 何时才另起新段（除长度超限外）
只有以下四种情形才设立新自然段：
1. **人物对话**（问答、引语角色的切换）
2. **重要转折**（语义方向反转、提出反例或设问）
3. **时间/空间跨越**（叙事场景、朝代、案例切换）
4. **核心观点升华**（从举例进入总结、从具象进入抽象结论）

#### 六条硬规则（从第一章踩坑中提炼）

| # | 规则 | 典型反例 | 正确做法 |
|---|------|----------|----------|
| 1 | **逗号不断段** | `这个心体，`¶`佛家讲的心体…` | 逗号后的内容归入下段 |
| 2 | **无孤悬片段** | `…程度。我们`¶`今天一起讨论…` | "我们"归入下段，保持句子完整 |
| 3 | **语义连续不切断** | `最尊最上最第一。`¶`一种最高的度…` | 论点→论据→结论 保持同段 |
| 4 | **同一话题讨论归一段** | "乐"字三种读音被中间切断 | 整个话题讨论归一段，在话题转换处分段 |
| 5 | **三句义完整** | 三句义论述（如来说X，即非X，是名X）被拆散 | 一组三句义及其解释保持同段 |
| 6 | **引文+解释同段** | 引用经文后立刻断段 | 经文引用与紧跟的解释放在同一段 |
| 7 | **先辨句法再合并** | `不是你去降伏，`+`那些发了菩提心的人…`直接拼成“降伏那些人” | 先判断后句主语、前句宾语和口语停顿，避免合并后改变原意 |

#### 分段锚点选择（优先级递降）

1. **话题转换**：从讨论 A 概念转向 B 概念
2. **叙事转折**：时间/人物/场景切换
3. **论证层次**：从举例转向总结、从总结转向新论点
4. **长段内的自然呼吸点**：一个完整论证链结束，下一个开始

### Step 3：通读复查

逐段检查：
- [ ] 有无孤悬片段（几个字单独成段）
- [ ] 有无逗号结尾的段落
- [ ] 有无超 550 字的段落需要拆分
- [ ] 有无语义被硬切的段落需要合并
- [ ] OCR 残留是否清干净
- [ ] **跨章用词是否与已交付章节一致**（分目题、人名、术语）
- [ ] **是否已调用 present_files 推送给用户**（易漏：处理完就去同步 Skill，结果产物从未展示）

## 常见陷阱

- **错误粘连改变句法**：原稿的逗号或换行可能代表口语停顿，不能只删除分隔符机械拼接；须先判断主谓宾关系。
- **用通行版本覆盖讲者原话**：典故、经文或名言疑似有误时，若没有音频依据，不直接替换成记忆中的标准表述。
- **段落过碎但形式合规**：即使每段都超过150字，也要复查“例证—解释—结论”是否被拆散；段长合格不等于语义完整。
- **讲者的文字游戏被段落边界切断**：王德峰常做字词拆解式修辞（如把“所知障”翻转说成“知是种障”、“圣贤”倒成“贤圣”）。这类拆解的前后两句必须同段，否则读者看不出修辞意图。
- **对偶/排比句被拆两段**：如“也不在佛法上着相”与“也不在世法上着相”，是成对出现的，必须同段。
- **顶真/接力句被段落边界切断**：讲者常用上一句末尾的词作下一句开头（如“消业要被指点的。指点我们的就是佛法。”“于是有了信，越来越坚定。”）。**顶真的两句必须同段**，否则衔接词悬空、气势断裂。修法：不是把两句硬拼，而是把分段点移到该论证单元的更早处。
- **同话题被段界劈成两半**：连续的背景交代（如“合起来叫四众。佛有四众弟子。”与“分了在家和出家，分了男性与女性”）不可断开；判断标准是下段首句是否能独立成立，不能独立就必须并回上段。
- **为凑段长而牺牲语义完整**：段长合格 ≠ 语义完整。每章落盘后必须逐对检查「上段末句 + 下段首句」，确认不是同一句话、同一修辞或同一话题被切开。
- **跨章专有名词不统一**：佛经分目题、人名、术语在不同章用了不同写法（如“希有”/“稀有”）。每完成一章要回头比对已交付章节，统一为原文章题的写法。
- **设问与作答被段界切开**：讲者口语体大量使用自问自答（如“那么这个常在哪里？”→ 下段“当然，人类社会…会发明出常来的”）。**设问句与其作答必须同段**。修法：若两段的字数之和会突破 400 字上限，就把设问句整体移到作答段开头（而不是把两段硬拼），上段在设问前收尾。
- **原始章节文件可能跨界**：讲读稿不是严格按经文分品切分的——一章原文里可能夹着讲座的分点编号（如“我们讲第十二点：住相与我执同”）和下一品的引子（如第九品原文末尾整段讲燃灯佛授记，而授记正文在第十品）。处理前先通读全章确认内部板块，按板块分段，不要按原始行号机械切。
