# PDF→EPUB 段落重组检查清单

## 一、什么情况说明问题在“文本重组”而不是“样式”
- 大量段落在无句号、问号、叹号处断开
- 编号条目被拆成两段或三段
- 阅读器里出现明显断裂词，如“一个攻 / 击”
- 同一自然段跨页后被错误拆成多个段落

## 二、默认合并规则
1. 当前段是章节标题 → 保留
2. 当前段是小标题，且满足上下文条件 → 保留
3. 当前段是编号条目开头 → 作为段落开始保留
4. 当前段若无结束标点 → 默认与下一行合并
5. 只有遇到以下条件才允许断开：
   - 当前段已经正常结束（。！？；：或可靠引号结尾）
   - 下一段是明确章节标题
   - 下一段是新的编号条目
   - 下一段是上下文成立的小标题

## 三、重点误判源
- 只按“短句”判小标题
- 把 `一、/1.` 之类的编号条目当 heading
- 只做页内合并，不做章节内二次合并
- 只看截图局部，不做整书探针

## 四、整书自检最低配置
- 统计总页数、原始行数、合并次数
- 统计每章疑似残留问题数
- 输出 4 类回查：
  - 关键截图片段
  - 开头章节
  - 中部章节
  - 末尾章节
- 单列“疑似原书少句号例外”，不要混在误分段里

## 五、交付建议
- 最终至少交付 3 个文件：EPUB、报告、脚本
- 版本号递增，不覆盖旧版本
- 若用户用本地阅读器查看，同步一份到桌面或指定目录
